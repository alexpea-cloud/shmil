# Sorteringsmerker (gjenskapt)

Vektorgjengivelser av de nasjonale sorteringsmerkene for glassemballasje, metallemballasje,
papir, papp og drikkekartong, tegnet etter skjermbilder fra BIR, Hadsel kommune og sortere.no.
Farger målt fra originalene: glass #28A69A, metall #6F7D7D, papp/papir #0082BE.

Merkeordningen forvaltes via sortere.no (LOOP). Regler: brukes i farger, kvadratisk med hvit kant,
tekst utenfor fargefeltet, ingen endringer på merkene. Bytt gjerne til de offisielle filene fra
merkeordningen når de er tilgjengelige.
